# AI-Use Declaration — FABES GLOBAL Advanced Database Portfolio

## Tool Used

## How AI Assistance Was Used

ChatGPT was used as a learning and drafting assistant during the preparation of this portfolio. Assistance included explaining database concepts, suggesting SQL queries and index strategies, outlining transaction and concurrency tests, comparing NoSQL data models and proposing distributed database architecture documentation.

## Verification and Responsibility

I am responsible for reviewing the submitted work, checking technical accuracy, and ensuring that the documentation reflects the actual implementation and available evidence. AI-generated suggestions were verified against the database results, scripts and official documentation.
