# AI-Use Declaration — FABES GLOBAL Advanced Database Portfolio

## Tool Used

OpenAI ChatGPT.

## How AI Assistance Was Used

ChatGPT was used as a learning and drafting assistant during the preparation of this portfolio. Assistance included explaining database concepts, suggesting SQL queries and index strategies, outlining transaction and concurrency tests, comparing NoSQL data models, proposing distributed database architecture documentation, and helping organise the GitHub repository.

ChatGPT also assisted in drafting parts of the README, portfolio summary, technical reflection, references, and supporting documentation.

## Verification and Responsibility

The project author is responsible for reviewing the submitted work, checking technical accuracy, and ensuring that the documentation reflects the actual implementation and available evidence. AI-generated suggestions should be verified against the database results, scripts, official documentation, and course requirements.

The portfolio distinguishes implemented PostgreSQL and MongoDB work from proposed replication, sharding, backup, and monitoring infrastructure.

## Declaration

This declaration is intended to transparently describe the AI assistance used during preparation of the portfolio. The author should review and amend it to ensure it accurately reflects their work and complies with the institution's assessment and academic integrity policies.
